P-gina-Fotos-Profissionais
Site institucional da EcoAmorim Fotografia — estúdio especializado em fotografia de natureza, paisagens e vida selvagem, com sede em Recife, Pernambuco.

Estrutura do Projeto

ecoamorim-fotografia/ ├── index.html # Página principal ├── style.css # Estilos do site ├── README.md # Documentação └── img/ # Pasta de imagens ├── camera.jpg # Imagem de destaque (hero) ├── p1.png ~ p4.png # Ícones dos serviços ├── mail.png # Ícone de e-mail └── galeria-1.jpg ~ galeria-6.jpg # Fotos da galeria

plaintext

Como Usar?

Faça um fork ou clone deste repositório
Coloque suas imagens dentro da pasta img/ com os nomes correspondentes
Abra o arquivo index.html no navegador para visualizar
Personalize textos, cores e imagens conforme necessário

##Tecnologias:

Layout responsivo (celular, tablet e desktop)
